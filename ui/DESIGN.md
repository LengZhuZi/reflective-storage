# 本机面板的视觉系统

这份文件是面板的唯一视觉规范。组件按它实现，不按实现者的默认口味。

## 简报（这份 UI 是什么）

一个**本机检查器**：单用户、离线、数据密集，用来回答三个问题 —— 记了什么、为什么记、
要不要复核。它不是营销页，所以不适用「落地页」那套排版手法（大 hero、滚动叙事、
bento 营销块）；它是一个 devtool 面板，参照物是 Linear / Raycast / lazygit 这类
**每天看几眼、键盘优先、信息密度高**的界面。

- 语气：克制、准确、不解释自己。术语用系统里的原词（J7 重排、作用域、衰减），不翻译成
  「智能匹配」「记忆热度」这类营销词。
- 反模式：霓虹发光、紫色渐变、三张等宽卡片、装饰性状态点、`—` 破折号、版本号当装饰、
  空状态只写「暂无数据」而不说下一步。
- 反模式（数据层）：把记忆原文当 DOM 拼（它是不可信输入）。
- 反模式（图谱）：把节点平铺成一堆没有归属的点；标签按圆心距离避让；气泡互相压。

## 刻度

| 刻度 | 值 | 理由 |
| --- | --- | --- |
| DESIGN_VARIANCE | 4 | 三栏外壳是结构性的，不需要再制造不对称；图谱视图内部自带不对称 |
| MOTION_INTENSITY | 4 | 只做状态反馈（hover / focus / 视图切换 / 图谱高亮），140-200ms |
| VISUAL_DENSITY | 8 | 驾驶舱密度：行高 32px、发丝分隔线、数字与 id 全用等宽字体 |

## 颜色

单一强调色（青玉），状态色只在**真状态**上出现。暗色是主模式，浅色是同一套 token 的对照。

| Token | 暗色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#08090A` | `#FBFBFA` | 页面底 |
| `--surface` | `#0E1011` | `#FFFFFF` | 面板/表格底 |
| `--surface-2` | `#141719` | `#F4F5F6` | 悬浮、选中行、输入框 |
| `--line` | `#1D2124` | `#E6E7E9` | 发丝分隔线（1px，不重复叠加） |
| `--line-strong` | `#2A2F34` | `#D3D5D9` | 边框、输入框描边 |
| `--fg` | `#E7EAEC` | `#15181B` | 正文 |
| `--fg-dim` | `#98A1A8` | `#5A626B` | 次要文字、meta |
| `--fg-faint` | `#6A727A` | `#8A9098` | 时间戳、id |
| `--accent` | `#3FBF8F` | `#0F7A5A` | 唯一强调色：主按钮、焦点环、active 状态、图谱焦点 |
| `--on-accent` | `#04221A` | `#FFFFFF` | 强调色上的文字 |
| `--warn` | `#D9A25B` | `#8A5A10` | 待确认、cold、冲突边 |
| `--bad` | `#E0685F` | `#B3261E` | 删除、错误、被取代边 |
| `--info` | `#7BA7D9` | `#2A5C99` | 链接、说明性提示 |
| `--focus-ring` | `#3FBF8F` | `#0F7A5A` | `:focus-visible` 外环，2px + 2px offset |

对比度：正文 ≥ 7:1（AAA），次要文字 ≥ 4.5:1，禁用态允许 3:1。所有颜色都在
`ui/src/styles/tokens.css` 里定义一次，组件里不出现裸色值。

## 字体

- 正文：`-apple-system, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`（不引 web font，离线可用，也不使用 Inter 作为默认）
- 数字 / id / 时间 / 判断码：`ui-monospace, "SF Mono", Menlo, "JetBrains Mono", monospace`
- 对比度靠字重和颜色拉开（500/600 两级），不靠字号堆砌。

| 级别 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 22 / 30 | 600 | 视图标题（每屏一个） |
| H2 | 15 / 22 | 600 | 区块标题 |
| H3 | 13 / 20 | 550 | 行内小标题、表格表头 |
| Body | 13 / 20 | 400 | 正文、记忆原文 |
| Small | 12 / 18 | 400 | meta、辅助说明 |
| Mono | 12 / 18 | 400 | 数字、id、时间、gate 名 |

比率 1.2，最长行宽 `68ch`（记忆原文允许换行，长 id 用省略号 + `title`）。

## 间距与栅格

- 基准 4px：`4 8 12 16 20 24 32 48`
- 行高 32px（表格行）、卡片内边距 12/16、区块间距 20
- 三栏：左栏 224px（可折叠 56px）、主区自适应（最小 480px）、右检视栏 380px
- 断点：`< 1080px` 检视栏改为底部抽屉；`< 860px` 左栏收成图标条；`< 640px` 单栏

## 圆角与阴影

- 圆角：`--r-sm 6px`（chip/输入框/按钮）、`--r-md 10px`（卡片/行容器）、`--r-lg 14px`（面板/弹层）
- 阴影只用两级：`--e1`（悬浮卡片）、`--e2`（弹层/命令面板），都带色相阴影而不是纯黑。

## 动效

| 场景 | 时长 | 曲线 | 属性 |
| --- | --- | --- | --- |
| hover / focus | 140ms | `ease-out` | `background-color`, `border-color`, `color` |
| 视图切换 | 180ms | `cubic-bezier(.16,1,.3,1)` | `opacity` + `translateY(4px)` |
| 检视栏开合 | 200ms | `cubic-bezier(.16,1,.3,1)` | `transform: translateX(8px)` + `opacity` |
| 图谱选中 | 160ms | `ease-out` | `r`, `opacity`, `stroke-width` |
| 数字变化 | 240ms | `ease-out` | 只做颜色闪烁，不做滚动计数 |

`prefers-reduced-motion: reduce` 下全部改为 0ms（不保留位移）。

## 组件规范

- **命令栏（44px）**：左「反思存储」+ 当前库路径（mono，省略中段）；中 `⌘K` 搜索入口（可点）；
  右 引擎状态 chip + 账号菜单。无装饰性状态点，除引擎真降级时出现一个 warn chip。
- **左栏导航**：每项 = 图标 + 名称 + 计数（mono）。当前项用 `--surface-2` 底 + 左侧 2px `--accent` 条。
- **表格行**：32px 高，hover 变 `--surface-2`，选中左侧 2px accent、背景 `--surface-2`。
  列：状态 chip / 类型 / 内容（可截断）/ 主题 / 重要度（mono 两位小数）/ 距今（mono）。
- **chip**：11px、`--r-sm`、1px 描边、无填充（状态色只体现在文字与描边上）。
- **检视栏**：头部（内容 + 类型/作用域）、meta 网格（等宽数字）、路径、轨迹时间线（gate/action 用 mono）、操作区（复制 id / 合并候选 / 删除）。
- **图谱**：见下节。分段控件（关系图 / 分层）用的是 `--surface-2` 底 + 选中项 `--surface` 面，
  不抢主按钮的样式；左栏结构树的行高 28px（记忆叶子 26px）、缩进 10/22/40px。**空状态**：说明「库里还没有记忆」+ 一行命令提示（怎么让它记）。**加载**：骨架行，不用转圈。
- **复核卡片**：一次一条，问题原文 + 选项按钮（编号 1..n 可键盘直选）+ 进度 `3/12`。
- **命令面板**：`⌘K`/`Ctrl+K` 打开，输入即过滤（记忆 / 视图 / 动作），↑↓ 选择，Enter 执行。

## 图谱

参照物是**结构**，不是点云：一张图要能回答「这个项目里记住了什么、分几块、彼此什么关系」。
两种画法共用一份数据、一套缩放平移（Cytoscape 自带的）和同一个左栏：

| 模式 | 画法 | 回答的问题 |
| --- | --- | --- |
| 关系图 | 力导向（Cytoscape + `fcose`，复合节点成簇） | 谁和谁有关系、主题分成哪几团 |
| 分层 | 深度即横轴的整齐树（坐标自己算，`preset`） | 主题 → 代码路径 → 记忆，项目的结构长什么样 |

渲染是 **Cytoscape.js（canvas）**：上一版是 1000 行手写 SVG（布局、碰撞、缩放、命中判定全自己
实现），节点一多就卡，主题气泡也只是画了个圈。换库之后这些都不写了，`graph.tsx` 只剩
「塞什么数据」和「点了干什么」。图谱库是**动态 import** 的独立 chunk（约 570KB），
不进首屏 —— 概览/列表/设置不加载它。

左栏**永远是**那棵分层树（主题 → 路径 → 记忆，带计数，可折叠）——不是平铺列表。
平铺列表看不出「这条属于哪个主题、哪个文件」，而复核时先要看的正是这个。

### 关系图

- 力导向，布局**确定性**：初值按索引摆在螺旋上（不用随机数），fcose 用 `randomize: false`
  从这些点收敛。同一份数据两次打开位置一致。
- **主题是复合节点**（compound node），不是画的圈：拖动主题，里面的记忆跟着走；布局器也按
  簇来摆位。这是换库最大的收益 —— 主题从「装饰」变成了结构。
- 节点编码（四个维度，图例里全写明）：

  | 维度 | 编码 |
  | --- | --- |
  | 半径 | 重要度（在**可见集里归一化**：库里重要度常集中在 0.6–0.95，不归一化就只差 2px，看不出来） |
  | 填色 | 作用域：项目 `--accent`、全局 `--info`、会话 `--warn`（低饱和填充，`background-opacity: 0.18`） |
  | 描边色 | 状态：active `--accent`、cold `--warn`、archived `--fg-faint`、superseded `--bad` |
  | 虚线描边 | 模型所记且未经确认（`trust < 0.8`）—— 来源权重的唯一视觉标记 |

  canvas 上画不出第二个描边，所以「虚线」这条改由**描边线型**承担（上一版是虚线外环）；
  状态本来还有颜色在区分，两者不冲突。

- 合并视图（`全部项目`）下节点还带 `project`：悬停卡和 `title` 里写归属项目，记忆列表里给每条
  加一个项目 chip。**不给项目分配颜色**：颜色已经给了作用域和状态，再加一套色板就得再给一套
  图例，而归属用文字已经说清楚了。
- 边：取代/冲突 = 粗虚线、依赖/延伸 = 细点线、同路径 = 点线、同主题/相似 = 细实线。
  **有方向的边加箭头**（取代和依赖方向反了意思就反了）。
- 标签：默认**全不显示**，只有判过不打架的才加 `label-shown`（焦点/悬停/选中优先，其余按重要度
  取，上限 10 条）。判据是**估算矩形**：折行会压到下面的节点上，所以标签一律单行（24 字截断 +
  `text-max-width: 240px`），障碍包括所有记忆节点圆和分组标题。Cytoscape 不管标签重叠，
  这一段是必须自己写的。
- 悬停卡：id、类型、作用域、来源（模型所记带 trust 值）、项目、主题、路径、重要度、召回次数。
- 交互：点击=聚焦并居中，拖动=挪位（分组拖动带着整团），滚轮=缩放，拖空白=平移，`f`=适配，
  `Esc`=回全库概览，方向键=就近选择，Enter=打开检视栏，筛选 chip = 边类型 + 状态。

### 分层

- 深度即横轴：`库 → 主题 → 路径 → 记忆`，每层一列，中间用折线（`curve-style: taxi`）牵起来。
- **这里不用复合节点**：复合节点的语义是「框住子节点」，父框必须一路包到最右列的叶子上，
  四个深度会叠成一个大框（试过，全挤成一列）。所以分组退化成了普通矩形节点 + 连线。
- 坐标在 `elements` 里自己算（行号 × 26px）：树是「深度 → 横坐标，叶子顺序 → 纵坐标」，
  二十行就能算准，还能顺手把折叠算进去（折叠的分组占一行、不展开子节点）。
- 记忆叶子 = 小圆点 + 右侧截断标签；行距是算出来的，所以**不做**标签碰撞检测（那里不可能重叠）。

### 空状态与无数据

- 无节点不做「假图」，直接给空状态和「先去记一条」的命令提示。
- 有节点但无边：图照画，中间一行说明「同主题、同路径、取代/冲突、高相似会自动连成边」。

## 无障碍

- 所有可交互元素可见 `:focus-visible` 环；不使用 `outline: none` 后不给替代。
- 表格行是 `role="row"`，键盘可达；图谱节点同样可 Tab 聚焦（`tabindex` + `role="button"` + `aria-label`）。
- 触控目标 ≥ 32px（面板密度下），窄屏 ≥ 44px。
- 一切动效尊重 `prefers-reduced-motion`；删除/合并等不可逆操作必须二次确认，确认框里显示被删内容。

## 实现约束

- 源码在 `ui/`，Vite + Preact + TypeScript；不引 UI 框架、不引图标库（图标是手写
  16px 线性 SVG，统一 1.5px stroke，风格一致即可；图谱是数据可视化不算装饰性 SVG）。
- 构建产物 `ui/dist/` **提交进仓库**：使用者不需要装 node_modules 就能用面板。
- 渲染一律走 Preact 的文本节点（等价于 `textContent`），禁止 `innerHTML` /
  `dangerouslySetInnerHTML`：记忆原文是不可信输入。构建后由测试断言产物里没有它们。
- 所有请求走既有 `/api/*`，接口形状不改；改状态必须带 `x-csrf: 1`。
